Inspect calls

Click a call to inspect it. Shift-click selects a range; ⌘/Ctrl-click toggles individual calls. ↑/↓ moves the selection; Shift-↑/↓ extends it. The × removes a selection.

Chevrons open nested calls. Drag the divider to resize the list and inspectors. Click a source location to filter.

Run groups calls from one execution of a dbg! block. Source location groups repeated calls from the same place.

Filter syntax

Terms narrow the selection together. Quote text containing spaces.

file:scratch.ll
File path contains this text
file:scratch.ll:7:3
Exact line and optional column
expr:"(+ x x)"
Source contains this expression
status:running
running, returned, error, cancelled
time:>100ms
Elapsed wall time; also <1s
run:ID / call:ID
Evaluation / call and descendants

Plain words search expressions. Click a file, location, status, or evaluation to add a filter.
